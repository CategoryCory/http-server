# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-06

## Context

Design choices in this project are easy to forget or misremember, and the reasoning behind them is not visible in the code.

## Decision

We will record significant architecture decisions as ADRs in `docs/adr/`, using [template.md](template.md).

## Consequences

Decisions and their rationale are discoverable in the repository history. Each significant decision costs a short write-up.
