# Architecture Decision Records

An ADR captures one significant decision: the context, the choice, and its consequences.

## Conventions

- One file per decision, named `NNNN-short-title.md` (zero-padded, sequential).
- Copy [template.md](template.md) to start a new one.
- Records are immutable once accepted. To change a decision, add a new ADR and mark the old one `Superseded by NNNN`.
- Statuses: `Proposed`, `Accepted`, `Rejected`, `Deprecated`, `Superseded by NNNN`.
